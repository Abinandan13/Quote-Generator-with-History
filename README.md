# Quote Generator with History

A modern, full-stack web application with a premium SaaS-style interface that fetches inspiring quotes from the DummyJSON API, automatically persists every quote into a local SQLite database using SQLAlchemy ORM, and maintains an interactive, searchable quote history list.

## Key Features

1. **Modern SaaS Interface:** Clean card layout with subtle gradients, decorative quotation marks, and smooth fade transitions.
2. **Real-time Live Backend Indicator:** A status indicator pill in the navigation bar automatically confirms backend and database connectivity.
3. **Automated Persistence:** Every quote generated by clicking **New Quote** is automatically saved to SQLite with UTC timestamps.
4. **Resilient Error Handling:**
   - Detects offline networks, unreachable backend, timeouts (504), external service errors (502), and database errors (503/500).
   - In-card **Retry Now** button allows instantaneous recovery without page reloads.
5. **Interactive Quote History:**
   - Displays quotes ordered newest first.
   - Shows dynamic quote counter badges and readable timestamps.
   - Persists across browser refreshes and restarts.
6. **One-Click Clipboard Copying:** Smoothly copies formatted quote and author text with fallback support for all browser environments.

## Tech Stack

- **Frontend:** HTML5, CSS3 (Custom Properties, Flexbox, Grid, Media Queries), Vanilla JavaScript (ES6+)
- **Backend:** Python 3.10+, FastAPI, Uvicorn (ASGI server)
- **HTTP Client:** HTTPX (asynchronous client with connection pooling and timeouts)
- **Database & ORM:** SQLite 3, SQLAlchemy 2.0+

## Database Schema (SQLite: `backend/quotes.db`)

Table: `quotes`

| Column | Type | Constraints | Description |
|---|---|---|---|
| `id` | `INTEGER` | Primary Key, Autoincrement, Index | Unique quote record ID |
| `external_quote_id` | `INTEGER` | Nullable, Index | External ID from DummyJSON |
| `quote_text` | `TEXT` | Not Null | Quote text content |
| `author` | `VARCHAR(255)` | Not Null | Author name |
| `created_at` | `DATETIME` | Not Null, Default UTC | Timestamp of fetch and save |

## API Endpoints

### 1. `GET /health`
Checks backend server status and verifies database read connectivity.
- **Response (200 OK):**
  ```json
  {
    "status": "healthy",
    "module": "Module 4 – Testing, Error Handling and Final Polish",
    "database": "connected"
  }
  ```
- **Error (503 Service Unavailable):** Returned if the database connection fails.

### 2. `GET /api/quotes/random`
Fetches a random quote from DummyJSON, saves it into SQLite, and returns the persisted record.
- **Response (200 OK):**
  ```json
  {
    "id": 1,
    "external_id": 588,
    "external_quote_id": 588,
    "quote": "There's no one with intelligence in this town...",
    "quote_text": "There's no one with intelligence in this town...",
    "text": "There's no one with intelligence in this town...",
    "author": "Rumi",
    "created_at": "2026-11-25T13:25:00.000000"
  }
  ```
- **Error Codes:**
  - `504 Gateway Timeout`: External DummyJSON API timed out.
  - `502 Bad Gateway`: External API returned non-200 or empty quote.
  - `500 Internal Server Error`: Failed to commit record to SQLite.

### 3. `GET /api/quotes/history`
Returns all saved quotes from SQLite ordered newest first (`created_at DESC, id DESC`).
- **Response (200 OK):** Array of quote objects. Returns empty array `[]` when no history exists.
- **Error (500 Internal Server Error):** Database query error.

## Installation & Setup

### Prerequisites
- Python 3.10 or higher
- Node.js (optional, for running frontend test scripts)
- Modern web browser (Chrome, Edge, Firefox, Safari)

### 1. Install Backend Dependencies
```powershell
pip install -r backend/requirements.txt
```

### 2. Start the FastAPI Server
```powershell
cd backend
python -m uvicorn main:app --reload --port 8000
```
- API Docs (Swagger UI): [http://127.0.0.1:8000/docs](http://127.0.0.1:8000/docs)
- Health Check: [http://127.0.0.1:8000/health](http://127.0.0.1:8000/health)

### 3. Launch the Frontend
Open `frontend/index.html` directly in any web browser, or serve it using Python's static server:
```powershell
cd frontend
python -m http.server 5500
```
Then navigate to [http://localhost:5500](http://localhost:5500).
